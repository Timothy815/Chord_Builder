# Chord Builder

Open index.html in a browser to use Chord Builder locally. Its styles,
fretboard logic, and synthesized audio are bundled in the HTML file.

Use **Show all fretboard notes** to toggle the note-name overlay.
Chord choices remain highlighted in either view.

Use the Left and Right arrow keys or the fret buttons to transpose a shape
one semitone at a time. The bass and root summary shows sounding octaves.

Choose **Open explore** to place any note, one per string. Click a selected
note again to mute its string. Recognized shapes show matching chord names.

## Publish on GitHub Pages

1. Extract this ZIP. Upload index.html to the top level of your GitHub
   repository on the main branch. You can also upload this README.
2. In the repository, open Settings → Pages. Under Build and deployment,
   set Source to Deploy from a branch.
3. Select main and /(root), then click Save. When the deployment finishes,
   Settings → Pages shows the site URL.

[GitHub Pages publishing documentation](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
